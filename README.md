# La Pazza Gioia

A responsive multi-page restaurant website recreated using HTML and CSS.

**[Live Demo](https://wilmetjph.github.io/la-pazza-gioia/)**

## About the project

This project was developed as part of a front-end web development course.

The objective was to recreate the official La Pazza Gioia restaurant website using HTML and CSS, focusing on responsive design, visual accuracy and consistency across multiple pages.

## Technologies

- **HTML5** — Page structure and semantic elements
- **CSS3** — Layout, styling and responsive design

## Pages

- Home
- About
- Menu
- Gallery
- Catering
- Takeaway
- Contact

## Project status

Completed as an educational front-end development exercise.
